# FundLien — Pre-Underwriting Engine (demo)

Demo estática del motor de pre-underwriting. Publicada para revisión interna.

**Qué se puede hacer aquí:** recorrer la pantalla completa (EN/ES, claro y oscuro),
ver el caso A con su scorecard, waterfall, evidencia citada y traza de auditoría, y
mover los cortes de la política de underwriting para ver el scorecard recalcularse.

**Qué NO:** puntuar un caso en vivo. El botón *Score case* llama al modelo, y eso solo
funciona dentro de Claude. Aquí sale deshabilitado.

Los cortes de puntuación, los topes de adelanto y la heurística del rango de settlement
son provisionales. Prototipo, no decide financiación.
